# CandyCoded

## Projects, tools & workshops by Candy Nwigwe

CandyCoded is the public home for my experiments, reusable tools, technical workshops, and documentation about building with data, AI, and automation.

The hub is intentionally lightweight: working software stays in its own repository, while this space explains what each resource is for, who it helps, and where to find the materials.
