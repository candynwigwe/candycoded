# CandyCoded

## Useful work, with a little spark ✦

CandyCoded is the public build space for Candy Nwigwe’s data, AI, automation, experiments, workshops, and technical notes.

I read the field, then build the play: working software stays in its own repository, while this hub explains what each resource does, who it helps, and where to try or reproduce it.

### [Reports](./docs/reports.md)
