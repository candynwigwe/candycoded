# Workshops

CandyCoded workshops make data, AI, and coding practical for the people using them.

## Coding, computer science & robotics

- **Status:** Available as community programming
- **For:** Beginners and young learners exploring coding and STEM
- **Focus:** Scratch, LEGO Robotics, debugging, coding challenges, and confidence-building
- **Context:** Delivered through Black Kids Code Calgary

## Responsible AI for teams

- **Status:** In progress
- **For:** Analysts, managers, and cross-functional teams adopting AI tools
- **Focus:** Practical AI use cases, data protection, validation, responsible use, and workflow design
- **Materials:** Public workshop materials will be linked here when approved for release

## Analytics for better decisions

- **Status:** Planned
- **For:** Teams that want to move from dashboard outputs to clear decisions
- **Focus:** KPI design, root-cause analysis, anomaly investigation, and data storytelling
- **Materials:** Planned
